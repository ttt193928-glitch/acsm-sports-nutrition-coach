# 营养学专业课程整理说明

这个文件夹用于把直播转录稿整理成可复制粘贴的课程文稿。原始材料保留在：

- `第二期上课视频/`：ACSM 运动营养学主线课程，含扫描版 PDF 和转录 txt。
- `减脂教练/`：减脂教练专题课程，适合作为进阶模块或案例模块。

## 推荐整理原则

每节课不要直接按转录稿顺序粘贴，而是拆成 6 个固定层次：

1. 本课定位：这节课解决什么问题，接在上一节哪里，给后面哪节课铺垫。
2. 原书内容：书上案例、定义、表格、结论，只保留本节真正讲到的部分。
3. 讲师解释：把口语化讲解改成书面表达，删掉调试声音、点名、闲聊和重复话。
4. 纠偏提醒：把“书上不严谨/翻译不好/容易误导”的地方单独列出来。
5. 拓展应用：讲师延伸到训练、减脂、运动员、教练服务、自媒体表达的部分。
6. 课后复盘：核心结论、可执行原则、下节课衔接、需要回 PDF 核对的页码。

## 单节课输出格式

每节课建议统一成：

```markdown
# 第 X 课：标题

## 一、本课要解决的问题

## 二、原书内容

## 三、讲师解释

## 四、关键纠偏

## 五、拓展与应用

## 六、本课结论

## 七、课后作业/复习题
```

## 清理规则

- 删除直播技术内容：声音、画面、点名、迟到、互动等待。
- 删除低价值重复：同一个观点连续重复时，保留最清楚的一次。
- 保留讲师个人判断，但要标注为“讲师观点”或“讲师提醒”。
- “书上说”和“讲师说”要分开，避免学生误以为都是教材原文。
- 涉及医学、疾病、补剂剂量、特殊人群时，整理成学习资料，不写成直接诊疗建议。

## 当前建议课程结构

主课按 `第二期上课视频` 整理，做成“运动营养学主线课”。`减脂教练` 不要混进主课正文，建议作为第二部分“减脂教练专题课”，用于案例、操作和应用。
